# /assets/icons/education — Logos de Instituições de Ensino

Coloque aqui os SVGs (ou PNGs) das instituições de ensino exibidas
na seção **Formação Acadêmica**.

## Convenção de nomes

Use o nome da instituição em minúsculas, sem espaços ou acentos:

| Arquivo | Exemplo de uso |
|---|---|
| `nome-da-faculdade.svg` | Faculdade XYZ |
| `nome-da-instituicao.svg` | Instituto ABC |

## Como integrar

Após adicionar os arquivos, avise para atualizar o HTML da seção
Formação Acadêmica, substituindo o emoji 🎓 pelo `<img>` com o logo.
