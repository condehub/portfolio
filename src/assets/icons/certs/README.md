# /assets/icons/certs — Logos de Certificações e Cursos

Coloque aqui os SVGs (ou PNGs) das plataformas e instituições
que emitiram certificados, exibidos na seção **Certificações**.

## Convenção de nomes

| Arquivo | Plataforma / Instituição |
|---|---|
| `udemy.svg` | Udemy |
| `coursera.svg` | Coursera |
| `alura.svg` | Alura |
| `rocketseat.svg` | Rocketseat |
| `dio.svg` | DIO |
| `google.svg` | Google (certificados Google) |
| `aws.svg` | Amazon Web Services |
| `nome-da-plataforma.svg` | Outras plataformas |

## Onde baixar SVGs

- https://svgl.app
- https://simpleicons.org
- Página oficial de cada plataforma

## Como integrar

Após adicionar os arquivos, avise para substituir o emoji do cert-card__icon
pelo `<img>` com o logo da plataforma correspondente.
