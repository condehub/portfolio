# /assets/icons/companies — Logos de Empresas

Coloque aqui os SVGs (ou PNGs) dos logos das empresas onde você
trabalhou/atua, exibidos nas seções **Sobre** e **Experiência**.

## Convenção de nomes

Use o nome da empresa em minúsculas, sem espaços ou acentos:

| Arquivo | Empresa |
|---|---|
| `pigz-logo.png` | Pigz · Orange Labs |
| `nome-da-empresa.png` | Outras empresas |

## Como integrar

Substitua o emoji/placeholder pelo `<img>` com o logo correspondente,
ex.: `<img src="assets/icons/companies/pigz-logo.png" alt="Pigz" />`.
